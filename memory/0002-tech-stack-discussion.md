# 对话记录 #2 - 技术栈讨论（更新）

**时间**: 2026-04-28
**参与者**: 用户、Claude Code
**主题**: 技术栈选型

## 用户需求（已更新）

- 类似 App 的体验
- 方便部署和编译
- 不受第三方系统影响
- 不受应用商场限制
- **没有服务器，需完全独立运行**
- **数据存储在本地**

## 方案更新

PWA 方案被排除（需要 HTTPS 服务器）。

Claude 重新推荐方案：

### 首选：纯 Web 本地版
- 技术：HTML + CSS + JS，localStorage 存数据
- 一个 HTML 文件双击即运行，零依赖
- 跨平台，手机/电脑都可用
- 未来可套 WebView 壳打包 APK，代码无需重写

### 备选：Capacitor 打包 APK
- 适合主要使用安卓设备的场景
- 需要 Android 开发环境

### 备选：Tauri 桌面应用
- 仅限桌面端

## 待用户确认

关键问题：**主要使用设备是什么？**
- 安卓平板/手机 → Capacitor 打包 APK
- 电脑/笔记本 → 纯 Web 或 Tauri
- 两者都有 → 纯 Web 最省事

确认后进入下一步：游戏核心玩法设计。
