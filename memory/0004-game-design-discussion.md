# 对话记录 #4 - 游戏核心设计确认

**时间**: 2026-04-28
**参与者**: 用户、Claude Code
**主题**: 游戏核心玩法与数据结构设计

## 用户需求确认

### Q1：关卡与内容范围
- 成语：覆盖中小学成语范围（约500-800个）
- 古诗：覆盖中小学必会古诗（约200-300首）
- 英语：小学+初中难度（约1000-1500个单词）
- 关卡数根据题库数量动态定，不预设固定数量
- 随关卡增加，难度逐步递增

### Q2：题目数据存储
- 单独 JSON 文件存储
- 两层结构：
  1. **原始数据层**：idioms.json / poems.json / english.json
  2. **出题逻辑层**：智能出题，错题选项要有迷惑性
- 离线应用，需提前做好题库
- 迷惑项从"相似难度 + 相似标签"的题目中选

### Q3：难度递进
- 按难度随关卡递进
- **不区分年级**（不按1-2年级/3-6年级分）

## 出题类型确认

| 科目 | 题型 |
|------|------|
| 成语 | 看图猜成语（4选1）、成语填空、成语释义选择 |
| 古诗 | 诗句补全、诗人/朝代配对、诗句释义 |
| 英语 | 看图选词（4选1）、单词释义选择、单词拼写 |

## 游戏机制确认

- ❤️ 生命值（3颗心/关）
- ⭐ 星级（最高3星）
- 🔒 关卡锁定（需前一关达标解锁）
- 🎁 每日奖励 + 💡 提示卡
- 📊 错题本
