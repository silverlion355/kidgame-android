## 1. 科目与内容范围

### 成语乐园
- **内容范围**: 覆盖中小学成语
- **目标数量**: 约 500-800 个常用成语
- **难度递进**: 按成语使用频率 + 理解难度分级

### 古诗天地
- **内容范围**: 覆盖中小学必会古诗
- **目标数量**: 约 200-300 首古诗
- **难度递进**: 按年级课标 + 理解难度分级

### 英语世界
- **内容范围**: 小学难度 + 初中难度
- **目标数量**: 约 1000-1500 个单词/短语
- **难度递进**: 按词汇等级（CEFR 对标）分级

## 2. 关卡设计

### 关卡数量原则
- **不预设固定关卡数**，根据题库数量动态生成
- 每个科目按难度分为多个"大关"（Difficulty Tier）
- 每个大关包含若干小关，小关内随机/智能出题

### 难度递进模型

```
Level 1-10   → 简单：常见成语/古诗/单词，选项差异大
Level 11-30  → 中等：较少见内容，选项迷惑性增强
Level 31+    → 困难：生僻成语/古诗/高阶词汇，高迷惑性
```

### 3.2 出题逻辑层（智能组卷）

**核心原则**：
- 错题选项要有**迷惑性**，不能随机乱选
- 同一科目内，迷惑项从**相似难度 + 相似标签**的题目中选
- 例如：猜"画龙点睛"时，干扰项选同为"动物类"或"写作类"的成语

**出题类型**：

| 科目 | 题型 | 说明 |
|------|------|------|
| 成语 | 看图猜成语（4选1） | 用文字描述画面 |
| 成语 | 成语填空 | 给出句子填成语 |
| 成语 | 成语释义选择 | 给释义选成语 |
| 古诗 | 诗句补全 | 给出上下句填空缺 |
| 古诗 | 诗人/朝代配对 | 给诗选作者/朝代 |
| 古诗 | 诗句释义 | 给诗句选正确解释 |
| 英语 | 看图选词（4选1） | 图片描述文字化 |
| 英语 | 单词释义选择 | 给中文选英文 |
| 英语 | 单词拼写 | 听音/看释义拼单词 |

## 4. 游戏机制

| 机制 | 说明 |
|------|------|
| ❤️ 生命值 | 每关初始3颗心，答错扣1颗，归零闯关失败 |
| ⭐ 星级 | 每关最高3星，取决于答对题数和用时 |
| 🔒 关卡锁定 | 需达到前一关指定星级（如2星）才能解锁下一关 |
| 🎁 每日奖励 | 连续登录给金币/提示卡 |
| 💡 提示卡 | 排除1个错误选项 / 显示提示文字 |
| 📊 错题本 | 自动记录错题，可针对性复习 |
