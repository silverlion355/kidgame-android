## 最终选择：纯 Web 本地版

## 需求约束

- 类似 App 的体验
- 方便部署和编译
- 不受第三方系统影响
- 不受应用商场限制
- 无服务器，完全独立运行
- 数据存储在本地
- **主要使用设备：手机（偶尔电脑）**

## 技术方案

| 项目 | 选择 |
|------|------|
| 运行形式 | 纯 Web 本地版（HTML 文件） |
| 前端技术 | HTML + CSS + JavaScript（原生，无框架依赖） |
| 数据存储 | localStorage（本地浏览器） |
| 目标设备 | 手机为主，电脑为辅 |
| 使用方式 | 手机浏览器打开 / 电脑浏览器打开 |

## 设计原则

1. **零依赖** — 无 npm、无构建工具，纯原生 Web 技术
2. **单文件可运行** — 核心逻辑可打包为单个 HTML 文件
3. **响应式设计** — 适配手机竖屏，兼顾电脑横屏
4. **本地优先** — 所有数据 localStorage，无网络请求
5. **轻量快速** — 加载快，适合小学生注意力特点

## 为什么不用框架？

- 零依赖部署，双击即可运行
- 代码量少，易于理解和维护
- 对小学生游戏来说完全够用
